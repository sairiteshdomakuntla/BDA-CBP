# Cricket Player Performance Analytics and Runs Prediction System

An academic project for IPL cricket data analysis, player statistics evaluation, and runs prediction built using Streamlit, Scikit-learn, Pandas, and Plotly.

## Project Structure
- `app.py` - Main Streamlit dashboard entry point.
- `pages/` - Multi-page Streamlit dashboards.
- `src/data_prep.py` - Data cleaning, preprocessing, and joining scripts.
- `src/stats.py` - Analytical computations and feature engineering.
- `src/model.py` - Machine learning model training and inference (RandomForestRegressor).
- `data/` - Raw IPL datasets (source: Cricsheet / Kaggle).
- `requirements.txt` - Project dependencies.
